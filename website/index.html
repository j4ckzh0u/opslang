deploy.ops 
#!/usr/bin/env ops run
// 一行脚本完成批量部署

hosts = ["web01", "web02", "web03"]
config = yaml.load_file("app.yaml")
version = config["app"]["version"]

// 批量并行部署，自动汇总结果
results = fleet.parallel(hosts, fn(h) =>
    ssh.run(h, "deploy.sh {version}"))

for r in results
    if r.ok
        print("✓ {r.host} 部署成功")

summary = fleet.summary(results)
print("完成: {summary.ok}/{summary.total}")

为什么选择 OpsLang？

我们重新思考了运维场景下的编程需求，打造了一门专为运维而生的语言。

🎯

单二进制部署

编译为 2.4MB 静态二进制，无运行时依赖。scp 到任意 Linux 机器即可运行。

⚡

双模式执行

既能 ops run 解释执行快速调试，也能 ops build 编译为独立二进制分发。

🐍

Python 般简洁

缩进语法、字符串插值、列表推导式。运维人员 10 分钟上手，无需学习 class/decorator。

🔐

SSH 原生集成

内置 SSH 客户端、SCP 传输、连通性检测。零配置密钥认证，告别 paramiko 依赖地狱。

🚀

Fleet 批量引擎

一行代码并发执行 10000 台机器。自动结果汇总、错误处理、滚动更新。

✅

声明式管理

ensure.file、ensure.service — Ansible 式幂等保证，重复运行无副作用。

📋

数据格式原生

JSON / YAML / TOML 一等公民，三引号嵌入配置文件，无需外部库。

🛠️

完整工具链

REPL 交互、语法检查、包管理、VS Code 插件、LSP 语言服务器。

🌐

跨平台编译

在 macOS 上为 Linux ARM64 编译，Docker/K8s/边缘设备全覆盖。

与现有方案对比

同一个任务：在 100 台服务器上检查 Nginx 配置并修复。

开始使用

三种安装方式，选择最适合你的。

📥 方式一：从源码构建

$ git clone https://github.com/opslang/opslang.git
$ cd opslang && make build
$ cp bin/ops /usr/local/bin/
$ ops version

🚀 方式二：直接下载二进制

$ curl -L https://github.com/opslang/opslang/releases/latest/download/ops-linux-amd64 -o /usr/local/bin/ops
$ chmod +x /usr/local/bin/ops

🎮 方式三：试用 REPL

$ ops repl
ops>>> name = "OpsLang"
ops>>> print("Hello, {name}!")
Hello, OpsLang!
ops>>> for i in range(5) { print(i) }
0
1
2
3
4

📝 第一个脚本

$ cat > hello.ops << 'EOF'
#!/usr/bin/env ops run
hosts = ["web01", "web02", "web03"]
for host in hosts
    print("检查: {host}")
EOF
$ chmod +x hello.ops
$ ./hello.ops
检查: web01
检查: web02
检查: web03
