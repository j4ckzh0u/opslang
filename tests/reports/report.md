## SDK Limitations Identified

1. `sys.cpu.usage()` - Not implemented on macOS. Workaround: use `sys.load()`.
2. `file.delete()` - Cannot remove non-empty directories. Must delete files first.
3. `file.append()` - Not registered in interpreter. Workaround: read + write.
4. `process.find_by_name()` - Hangs on macOS. Workaround: use `process.exec("pgrep")`.
5. `net.tcp_check()` - Rejects ports > 65535 with runtime error.
6. `file.read()`/`file.stat()` on missing files - Runtime error. Guard with `file.exists()`.
