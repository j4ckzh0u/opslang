# OpsLang 集成测试场景清单

## 测试环境
- host1: 192.168.1.188 (jackzhou, sudo)
- host2: 192.188.1.193 (root)
- host3: 192.168.1.151 (openclaw, sudo)

## 测试场景（30+）

### A. 系统信息收集（6个）
1. **A1**: 获取所有主机 CPU 信息
2. **A2**: 获取所有主机内存使用情况
3. **A3**: 获取所有主机磁盘使用情况
4. **A4**: 获取所有主机操作系统版本
5. **A5**: 获取所有主机网络接口信息
6. **A6**: 获取所有主机系统负载

### B. 文件操作（6个）
7. **B1**: 创建测试文件
8. **B2**: 读取文件内容
9. **B3**: 追加文件内容
10. **B4**: 复制文件
11. **B5**: 移动/重命名文件
12. **B6**: 删除测试文件
13. **B7**: 文件权限检查和修改

### C. 进程管理（4个）
14. **C1**: 列出所有进程
15. **C2**: 查找特定进程（如 sshd）
16. **C3**: 启动简单进程（sleep）
17. **C4**: 终止测试进程

### D. 网络检查（4个）
18. **D1**: HTTP GET 请求测试
19. **D2**: TCP 端口连通性检查（22端口）
20. **D3**: DNS 解析测试
21. **D4**: 网络接口列表

### E. 服务管理（3个）
22. **E1**: 检查 sshd 服务状态
23. **E2**: 检查 cron 服务状态
24. **E3**: 列出所有活跃服务

### F. 系统监控（3个）
25. **F1**: 实时监控 CPU 使用率（3秒）
26. **F2**: 实时监控内存使用（3秒）
27. **F3**: 磁盘 IO 统计

### G. 配置管理（2个）
28. **G1**: 读取 /etc/hostname
29. **G2**: 读取 /etc/os-release

### H. 批量操作（3个）
30. **H1**: 批量执行 uptime 命令
31. **H2**: 批量创建测试目录
32. **H3**: 批量清理测试文件

### I. 条件执行（2个）
33. **I1**: 如果 CPU > 50% 则报告
34. **I2**: 如果磁盘 > 80% 则告警

### J. 并行执行（2个）
35. **J1**: 并行收集所有主机信息
36. **J2**: 并行执行多主机命令

### K. 错误处理（2个）
37. **K1**: 访问不存在的文件
38. **K2**: 执行不存在的命令

### L. 综合场景（2个）
39. **L1**: 完整系统健康检查（CPU+内存+磁盘+负载）
40. **L2**: 自动化部署模拟（检查+备份+部署+验证）

## 测试要求
- 每个场景生成独立报告
- 记录执行时间、成功/失败状态
- 错误场景验证错误处理
- 生成汇总报告（HTML/JSON）

## 安全约束
- 不删除任何系统文件
- 只删除自己创建的测试文件
- 测试文件统一放在 /tmp/opslang-test-*/
- 测试完成后清理所有测试文件
