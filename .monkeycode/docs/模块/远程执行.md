# 远程执行模块

远程执行模块负责从目标选择到 SSH 连接、Runner 下发、任务执行和结果汇总的完整控制面。

## 组成

| 目录 | 职责 |
|------|------|
| `internal/inventory` | 主机清单、标签和目标匹配 |
| `internal/exec` | 并发执行、超时、结果聚合 |
| `internal/sshx` | 认证、主机密钥、连接池、命令、架构检测与 SFTP |
| `internal/runner` | 指令协议、registry、执行与签名 |
| `cmd/ops-runner` | 远端进程入口和 relay 子命令 |
| `internal/security` | 权限、审批、审计与资源限制 |

## 生命周期

控制端解析 inventory 和目标表达式，建立有界 SSH 连接，检测架构并确认 Runner，然后发送指令包。Runner 输出 JSON，控制端按主机归档成功、错误和退出码。

## 资源与错误

连接和命令都使用超时。SFTP 偏移原语传播 `context.Context` 取消。远端错误保留主机和操作上下文；聚合层保证每个输入目标对应一个结果。

## 测试

单元测试覆盖连接池、主机密钥与命令行为。受控 SSH server 和 SFTP server 覆盖真实协议交互，避免依赖外部测试主机。
