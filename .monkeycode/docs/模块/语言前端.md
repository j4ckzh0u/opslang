# 语言前端模块

语言前端把 `.ops` 源码转换为 AST，并为解释执行、Runner 指令生成和 AOT 编译提供统一输入。

## 组成

| 目录 | 职责 |
|------|------|
| `internal/lexer` | token、关键字、字面量、注释和行列错误 |
| `internal/parser` | 递归下降解析与语法错误 |
| `internal/ast` | 语句、表达式、task、ensure 和 report 节点 |
| `internal/interpreter` | 作用域、控制流、函数与 SDK 内置调用 |
| `internal/compiler` | Go 代码生成、模式选择、构建缓存与权限检查 |

## 依赖方向

Lexer 不依赖 Parser；Parser 依赖 token 与 AST；Interpreter 和 Compiler 都依赖 AST。SDK 桥接集中处理动态值到强类型 Go 参数的转换。

## 修改要求

语法功能需要同时覆盖合法输入、错误行列、解释器行为和 AOT 行为。新增标准库调用还需通过 opsspec 与 Runner 一致性检查。
