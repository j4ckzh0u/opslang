# 指令包

指令包是控制端与通用 Runner 之间的 JSON 契约。它与目标 CPU 架构无关，因此同一任务可发送给不同架构的预编译 Runner。

## 结构

核心字段包括协议 `version`、`task_id`、`dry_run` 和有序 `instructions`。每条指令至少包含操作名 `op`，并可包含参数和变量接收名。

## 执行状态

Runner 顺序执行指令并聚合数据、错误和警告。输出状态与退出码映射：

| 状态 | 退出码 |
|------|--------|
| 全部成功 | 0 |
| 部分失败 | 1 |
| 全部失败 | 2 |
| 协议或用法错误 | 3 |

## 签名

指令包支持 Ed25519 签名。Runner 配置 `--pubkey` 后会在任何操作执行前验证签名；缺失、解码失败或内容被篡改会产生结构化安全拒绝结果。
