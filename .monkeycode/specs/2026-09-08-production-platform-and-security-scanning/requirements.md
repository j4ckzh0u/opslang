# OpsLang 生产化控制面与安全扫描

## 目标

OpsLang 提供单平台的海量服务器运维闭环，并通过通用 security scanner 抽象接入外部扫描引擎。扫描引擎、漏洞数据库和控制面均可独立替换。

## 核心要求

- 控制端持久化任务、主机、阶段和扫描结果状态。
- 任务支持断点恢复、租约、取消、超时和幂等执行。
- 未登记操作默认拒绝，操作声明 capability 和副作用。
- 凭据通过本地加密存储或 Secret Provider 获取。
- 生产环境使用显式主机密钥校验。
- 调度器支持分批、限流、退避、流式结果和主机级隔离。
- 回滚基于变更事件和补偿动作执行。
- security scanner 通过通用 backend 接口接入，不绑定具体产品名称。
- 控制端维护统一漏洞数据库服务，目标机不长期安装 agent 或数据库。
- 外部扫描引擎通过临时静态二进制或控制端服务执行。
- 扫描报告包含引擎版本、数据库版本、覆盖率、发现项和策略结果。
- 技术失败、扫描发现和策略阻断必须分别建模。

## 扫描能力

扫描后端至少支持漏洞、SBOM、配置、Secret 和 License 能力声明。未实现能力必须返回明确的 unsupported 状态。

控制端保存扫描引擎版本、数据库版本、规则摘要和结果摘要。目标机只接收临时执行文件，扫描结束后清理。
